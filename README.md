# Reinos de Ceniza — MVP 0.1

Primer prototipo 2D del MMORPG.

Incluye:
- Movimiento del personaje
- Mapa 2D
- Árboles y tala
- Piedra, cobre e hierro
- Pesca
- Lobos, jabalíes y goblins
- Combate básico
- Loot de oro
- Nivel del personaje
- HUD e inventario básico
- Controles táctiles para Android

## Ejecutar
Abre `index.html` con un servidor web. En Replit puedes crear un proyecto HTML/CSS/JS y subir estos tres archivos.
